K-Nearest Neighbors (KNN)

What is KNN?
K-Nearest Neighbors is a supervised machine learning algorithm that predicts a new data point by comparing it with nearby training examples.

Features used:
User degree, common neighbors, neighborhood union size, Jaccard similarity, and degree product.

How it works here:
Existing connections are treated as positive examples and non-existing connections as negative examples. KNN estimates the link probability for candidate pairs, and the candidates are ranked from highest to lowest.

Viva Explanation

What is Link Prediction?
Link prediction is a graph-based technique used to predict possible future relationships between currently unconnected users.

Why is KNN used?
KNN compares candidate user pairs with previously observed connected and unconnected pairs using numerical features.

What is the output?
The system displays a ranked list of potential connections with their KNN link probabilities.
